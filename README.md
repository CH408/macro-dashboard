# Macro Regime Dashboard

A big-picture read on the world economy, built only from public market and economic data (St. Louis Federal Reserve economic database, Yahoo Finance, and official public releases).

This is not investment advice and not a recommendation to buy or sell anything. Figures may be late, missing or wrong; check the original sources.

The live page is `index.html`, served at https://ch408.github.io/macro-dashboard/
